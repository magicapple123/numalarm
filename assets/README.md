# assets 目录说明

## voice_button_sample.png —— 语音通话按钮示例截图

这是 `pyautogui` 图片匹配使用的「模板图」。程序会在聊天窗口区域内按
`config.yaml` 中 `match.confidence` 的置信度查找与该图最相似的位置，
命中后模拟点击，即触发语音拨打。

> 当前仓库内置的模板截取自实际运行环境（2560x1600），**换机器/换分辨率后必须重新截取**。

### 替换步骤（Windows + PC 版 QQ）

1. 登录 QQ，打开任意好友的聊天窗口；
2. 确保聊天窗口工具条上的「语音通话」按钮图标完整可见
   （鼠标不要悬停在按钮上，避免截到悬浮高亮态）；
3. 使用截图工具（`Win + Shift + S`）精确框选**按钮图标本身**，
   尽量贴边裁剪，不要包含聊天窗口背景；
4. 保存为 PNG，覆盖本目录下的 `voice_button_sample.png`（文件名保持不变）；
5. 运行 `numalarm test` 校准，确认「语音按钮匹配（不点击）」步骤 PASS。

### 要求与建议

- 截图与实际拨打必须在同一台电脑、相同的分辨率 / DPI / 显示缩放比例下；
- 不要缩放图片，保持 PNG 格式；
- QQ 更新导致按钮样式变化后，需要重新截取；
- 匹配不上（1003）时：优先重新截图，其次调低 `match.confidence`（如 0.75）；
- 误点击（点错位置）时：调高 `match.confidence`（如 0.85 ~ 0.9）；
- 建议在拨打时保持聊天窗口不被遮挡（本工具会自动前置窗口）。

## call_ringing_sample.png —— 无人接听判定模板（可选）

用于「无人接听自动重拨」的结果判定：拨打后通话窗口头部显示「等待对方接听」
文案，该模板用于确认"仍在响铃"状态——

- 窗口存在 + 模板命中 -> 仍在响铃，继续等待；
- 窗口存在 + 模板未命中（变为计时器/拒绝提示）-> 对方已接听或已拒绝，触达成功；
- 窗口关闭 + 全程仍为响铃状态 -> 无人接听，自动重拨。

### 替换步骤

1. 向任意好友发起一次语音通话（响铃即可，无需等结果）；
2. 截取通话窗口**顶部的「等待对方接听」文字**（黑底白字，不要包含尾部动画省略号
   和右侧图标），保存覆盖 `call_ringing_sample.png`；
3. 删除该文件则回退为时长阈值判定（`retry.no_answer_seconds`，精度较低）。
